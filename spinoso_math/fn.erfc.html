Function erfc 

Source 
pub fn erfc(value: f64) -> Result<f64, NotImplementedError>
Expand description

Calculates the complementary error function of the given value.

Domain: (-INFINITY, INFINITY)

Codomain: (0, 2)

§Examples

use spinoso_math as math;
assert_eq!(math::erfc(0.0), Ok(1.0));

§Errors

Because spinoso-math was built with the full feature, this function will always succeed and return the complementary error function of the given value.
